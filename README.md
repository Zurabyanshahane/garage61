# Garage61 Logo Maker

Pick any color and get the Garage61 logo in that color, ready to download or print.

Open `index.html` in a browser (no install, no server needed).

- **Color**: color picker, hex code, or preset swatches
- **Download PNG**: high-res (about 7800 px wide) with a transparent background, good for printing
- **Download SVG**: vector, scales to any size (stickers, signs, shirts)
- **Print**: prints only the logo
- **Share link**: the color is saved in the URL, e.g. `index.html#b91c1c`
- **Upload**: recolor a different SVG/PNG logo

## Files

- `index.html`: the whole app (the logo is embedded)
- `logo.svg`: the logo as a vector (traced from `logo-original.pdf`); shapes use `fill="currentColor"`
- `logo-original.pdf`: the original logo file

## Put it online

Repo **Settings → Pages → Deploy from branch**, then pick the branch and `/ (root)`.
